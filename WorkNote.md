# Work Note

A work note is an ephemeral document that preserves information important to the execution and review of a development task but unsuitable for inclusion in its description.

Use a work note to preserve context that would otherwise remain transient during task execution and could be lost between sessions or unavailable to a reviewer.

Work notes are working artifacts rather than project documentation. Store them under `<project>/.work/notes/` in a location excluded from version control. They may be removed after the task no longer requires their context.

Record information whose loss would make continuing or reviewing the work materially harder. Do not use a work note as a chronological activity log or as a substitute for durable project documentation.
